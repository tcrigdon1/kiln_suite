Other fixes this round:
- **A/V at cuts** (`sources.js`): the incoming clip's `<video>` is now pre-rolled ~0.5 s before the cut (delayed when the clip starts near the file's beginning) and element start-ups aim slightly ahead; y4 mean |drift| went from 18–118 ms to 7–27 ms per clip and the worst sample after a cut from 0.31 s to under 0.25 s.
- **Duration-less (live-style) WebM** (`media.js`): the end-seek that discovers the duration gets 15 s instead of 4 s, and if it still fails the container scan's duration is used — on a slow run `lf5` had imported the cue-less file with `duration = Infinity`.
- **Proxies vs. cache pruning** (`project-io.js`): `pruneCache` no longer deletes `proxy|…` records of the project's media.
- Tests: `t5.js`, `x3_perf.js`, `h12_export.js`, `lf3`, `lf4`, `lf6` addressed export-dialog selects by index and had been broken by the new first Preset select — indices updated. The test libs (`lib.js`, `handson/hlib.js`, `pass2/plib.js`, `longform/lflib.js`) now mark the welcome tour as seen when they create a project (a returning user), because the tour's overlay appeared 0.9 s into every fresh-profile test and raced with the first clicks (`y5` still exercises the tour explicitly). `lf3`'s batch-export cap raised 900 → 1500 s and `lf4` no longer stops polling on an empty first progress line: on this VM headless exports run at 15–25 fps depending on host load (an A/B with the new hooks disabled at runtime, `longform/bench_export.js`, showed no measurable per-frame cost from this round's code). `lf5` closes the late Relink dialog before its UI import.
