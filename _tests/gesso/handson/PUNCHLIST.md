# Gesso hands-on punch list

Hands-on QA pass driven only by real mouse/keyboard input (Playwright `page.mouse` / `page.keyboard`,
clicks on visible UI, `setInputFiles`, dispatched drop/paste events). Scripts: `handson/s*.js` (QA sessions) and `handson/p2-*.js` (Part 2 features).

Severity: crash / broken / wrong / awkward / cosmetic. Status: fixed / not fixed (+ why).

**Summary.** 18 entries: 0 crash, 4 broken (#2, #3, #13, #17), 8 wrong (#1, #4, #5, #6, #11, #14, #16, #18),
3 awkward (#7, #8, #12), 1 missing feature that Part 2 covers (#15), 2 not bugs (#9, #10).
Every entry is fixed except #8 (dock space; see the row). #18 was a defect in the new text-on-circle
feature, found and fixed during this pass. No console errors or page errors came up in any session.

Run it with: `sh handson/run-handson.sh` (12 scripts, about 3 min). Screenshots go to `handson/shots/`.

Note on file pickers: Chrome exposes the native File System Access pickers on file://; automation cannot
drive native OS dialogs, so the hands-on scripts remove `showOpenFilePicker`/`showSaveFilePicker` with an
init script. Gesso then uses its own `<input type=file>` / download fallbacks, which is what was tested.
