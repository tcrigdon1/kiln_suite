# Gesso pass 2 — punch list (review, bug hunt, memory, additions)

Second-pass review of the whole code base plus hands-on sessions with real mouse / keyboard / pen input
(Playwright). Scripts live in `_tests/gesso/pass2/`; `sh run-pass2.sh` runs them all (screenshots in
`pass2/shots/`). Severity: crash / data-loss / broken / wrong / perf / awkward / cosmetic.
Status: fixed / not fixed (+ why) / by design.

| # | Did / saw | Expected | Severity | Status |
|---|---|---|---|---|
| 1 | Warp (Flow Warp) brush dragged from near the top-left of a layer whose canvas is offset: `RangeError: offset is out of bounds` in `Session.saveChunk` (toolmonkey "raster warp"). The brush reach rect was fractional, so the chunk's `Float32Array` row copies ran past the end | No error, stroke applied | crash (tool stroke aborted) | fixed (`reach` is rounded to integer pixels before `ensure`/`saveChunk`) |
| 2 | Painted a gradient / Edit ▸ Fill on a layer: the layer canvas grew to the document size **plus a 48-px transparent apron** on every side (`growTo` always pads by `PAD`) — 8 % extra memory per filled layer, and strokes along the document edge did the same | Growth is clipped to the document when the painted rect is inside it | perf | fixed (`Layers.growTo(c, r, pad, limit, fill)` clips the padding to a limit rect; brush/pixel tools, fills and gradients pass the document) |
| 3 | Masks were always document-sized canvases (every adjustment / fill layer carries a 16.5 MB reveal-all mask on the 2400×1800 watch file) | Masks only cost what has been painted | perf (memory) | fixed: sparse masks — `mask.canvas` is a content-sized offset canvas, `mask.outside` is the implicit value beyond it. Brushes, fills, gradients, filters, transforms, Move, Canvas Size, Image Size, rotate/flip, Apply/Invert/Load mask, thumbnails and the Properties panel all understand it; `.kgesso` v2 stores `mask.bounds` + `outside`; v1 full-size masks are loaded and compacted (border value → `outside`) |
| 4 | Fill layers (solid / gradient) rendered into a document-sized canvas | A fill layer costs nothing | perf (memory) | fixed (fill layers are painted procedurally by the compositor over the dirty rect; `Layers.materialize()` renders real pixels for rasterize / copy / selection) |
| 5 | Layer-effect caches were aligned to a 256-px grid: an 888×888 shape with a drop shadow cached a 1792×1792 canvas (12 MB); 100 such layers in Kiln Lattice = 110 MB | Cache ≈ content + effect reach | perf (memory) | fixed (grid 32 px; the three watch files still render pixel-identical to their reference PNGs — max channel diff 1) |
| 6 | Every dirty-rect composite allocated and **cleared whole document-sized scratch canvases** for each masked layer, group and clipping stack (`U.scratch` clears the full canvas) | Clearing only what was used | perf | fixed (`U.scratch(w, h, rect)` tracks the used rectangle and clears just that; compositor passes the dirty rect everywhere it clips to it) |
| 7 | Painting on a document with many layers re-rendered **every** layer inside the dirty rect on each brush flush (no caching) | Only the edited layer is rendered while painting | perf | fixed (below/above painting caches in the compositor: two document-sized canvases keyed by a signature of the other layers; used automatically for documents ≥ 4 layers and ≥ 0.25 Mpx, disabled when a layer above uses a backdrop-dependent blend mode or is an adjustment) |
| 8 | Undo/redo of *any* step (even a selection change) bumped the version of **every** layer, so all 151 Lattice layers re-rendered their effect caches and thumbnails | Only layers that actually changed re-render | perf | fixed (`restoreState` keeps version, `_rv`, effect cache and thumbnails of layers whose canvases and settings are unchanged) |
| 9 | History memory cap only counted brush patches; state entries holding replaced layer canvases (transforms, filters that replace canvases, merges) were not counted, so "History memory" in Preferences could be exceeded without limit | Entries count the pixel memory they keep alive | perf | fixed (`Document.stateBytes`: canvases referenced by the new state but not the old one) |
| 10 | Closing a document kept its pooled scratch canvases (up to 24 document-sized canvases) and its history alive until the page was reloaded | Memory is released | perf (leak) | fixed (`closeDoc` drops composite/caches/history and trims the scratch pool to the sizes of the open documents; `doc:closed` event) |
| 11 | Filter dialog: a preview scheduled just before pressing OK (or Cancel) still ran after the dialog closed and **overwrote the committed result** with preview pixels not recorded in history (also visible as "fast preview" blur left behind) | Nothing runs after OK/Cancel | data-loss (intermittent) | fixed (`closed` flag checked before and inside the deferred preview) |
| 12 | Switched tools with a letter key in the middle of a brush stroke: the stroke stayed on the layer but no history entry was written (undo could not remove it), and the next stroke of that tool started from a stale snapshot | Stroke ends and is recorded; or the switch waits | data-loss | fixed (letter-key tool switching is ignored while a drag is in progress; `StrokeMixin.deactivate` finishes a live stroke if a tool is switched programmatically) |
| 13 | Ran a structural command (Layer ▸ Delete Layer, Crop, Save…) from the menu while a Free Transform / Mesh Warp / Warp session or a text edit was live: the session kept writing into a layer that no longer existed and recorded itself on top of the new state | The live session is committed first | data-loss | fixed (`Cmd.run` commits live sessions before every command except view/window/help/undo/redo/prefs) |
| 14 | Select ▸ Reselect was enabled after Image Size changed only the height (checked width only) → selection with the wrong size | Reselect disabled when the size no longer matches | wrong | fixed (width and height checked) |
| 15 | Select Brush allocated a fresh `W×H` visited buffer for every pointer event (12 MB per move on 4000×3000) | One buffer per stroke | perf | fixed (stamped `Uint32Array` reused for the stroke) |
| 16 | No readout of memory / compositing cost anywhere | Window ▸ Performance | missing | fixed (Window ▸ Panels ▸ Performance: layers / masks / effect caches / undo history / composite / paint caches, last composite time (cached or not), scratch pool, JS heap; "Compact memory" and "Purge history" buttons; the status bar shows the document's pixel memory, hover for the breakdown) |
| 17 | Pixels moved past the canvas edge could not be discarded on purpose (only "Trim to content" existed) | Layer ▸ Trim Layer to Canvas | missing | fixed (`layer.trimToCanvas`, enabled when the layer canvas sticks out of the document; Crop already honours Hide vs Delete) |
| 18 | Applying a layer mask / inverting a mask / loading a mask as selection worked on document-sized canvases only | Works for sparse masks | (follow-up of #3) | fixed (`Compositor.applyMask`, `Layers.invertMask`, `Layers.maskDocCanvas`; Layer ▸ Layer Mask ▸ Compact Layer Mask trims a painted mask) |
